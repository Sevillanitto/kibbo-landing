Contract Comparison Workbook

A revised contract with "minor updates" sometimes has one buried change that matters. This workbook lines up every version side by side so nothing slips through.

Get it free →
The problem

"Minor changes" is not a clause-by-clause account of what actually changed

When a counterparty sends back a revised contract, the honest version of what changed is rarely volunteered — you're expected to spot it yourself, buried in a document that otherwise looks identical to the last one.

This workbook puts every version's key terms in adjacent columns — price, duration, cancellation, liability, warranties — with a dedicated column that states plainly what changed between them.

Features
  • Side-by-Side Term Comparison — price, duration, cancellation, liability, and warranty terms, one row per clause
  • What Changed Column — a plain statement of exactly what's different between versions, per clause
  • Version Log — which draft is which, and when each was received
  • Automatic Flag Summary — every clause that changed, listed in one place
How it works

Step by step

  1. Enter each contract version's key terms into its own column, clause by clause.
  2. Fill in the What Changed column for every clause that differs between versions.
  3. Check the automatic summary for a complete list of every changed clause, so nothing gets missed.
  4. Decide which changes you can accept and which need to go back to negotiation.
Who it's for

Anyone reviewing a revised or re-issued contract

A renewed lease, an updated vendor agreement, a "final" contract after a round of negotiation — anywhere a new version needs to be checked against the last one.

What's included
  • Excel workbook
  • Side-by-side version comparison
  • Automatic changed-clause summary
  • Works in Excel, Google Sheets, and Numbers
