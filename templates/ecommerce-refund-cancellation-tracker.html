One refund from one retailer is easy to remember. Five requests across five different stores, each on its own clock, is exactly where things quietly go stale.

The problem

Refund requests don't send you a reminder when they stall

A refund or cancellation request that's been pending two weeks looks exactly the same as one submitted yesterday — unless you're actively tracking the date. Spread that across several retailers and it's easy to lose track of which ones are genuinely overdue and worth chasing, and which are still within a normal processing window.

This tracker logs every refund and cancellation request in one sheet, calculates the days since you requested it automatically, and flags anything that's been pending 14 or more days so the ones actually worth escalating are obvious at a glance.

Features
  • Multi-Retailer Log — every refund and cancellation request in one sheet
  • Auto-calculated days-since-requested for each entry
  • Auto-calculated summary flagging requests pending 14+ days
  • Status column for requested, processing, refunded, or disputed
How it works

Step by step

  1. Download the Excel tracker and log each refund or cancellation request — retailer, amount, and date requested.
  2. The days-since-requested column updates automatically as time passes.
  3. Check the summary tab for any request that's crossed the 14-day mark.
  4. Update the status column as each request moves toward resolution.
Who it's for

Anyone managing more than one open refund or cancellation request

Whether it's several online orders at once or a recurring pattern of slow refunds, this keeps every clock visible in one place.

What's included

  • Works on any device
