The problem

A renovation generates a paper trail — until it doesn't

Contracts, change orders, payment receipts, progress photos, and text messages with your contractor all pile up over the course of a project, scattered across email, your phone, and a folder somewhere. If a dispute comes up — over scope, cost, or quality — reconstructing that record from memory months later is exactly the situation you don't want to be in.

This pack keeps everything in one file as the project happens, so the record is already built if you ever need it.

Features
  • Contractor & Contract Details — the agreed scope, price, and terms in one reference page
  • Change Order Log — every change to the original scope, with the date and what was agreed
  • Payment Summary — a rollup of what's been paid and when
  • Photo Log — dated entries for progress and completion photos, organized by phase
  • Communications Log — key calls, emails, and messages with the contractor, dated
How it works

Step by step

  1. Fill in the contractor and contract details at the start of the project.
  2. Log every change order as it's agreed, not from memory afterward.
  3. Add photos and communications entries as the project progresses.
  4. Keep the payment summary updated so the full record is ready if you need it.
