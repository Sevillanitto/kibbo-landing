Internet / Broadband Service Incident Log

One bad night is easy to dismiss. A dated log of every outage is a pattern — and a pattern is what gets a compensation claim taken seriously.

Get it free →
The problem

"It's been down a lot lately" doesn't get you far

A provider weighing a compensation claim or a penalty-free exit wants specifics: how many incidents, how long each one lasted, and what the guaranteed minimum was supposed to be. Reconstructing that from memory after the fact almost always understates it — and a vague impression is easy to dismiss.

This log records every incident as it happens and auto-calculates the downtime for each one, so weeks of scattered bad nights add up to a documented, provable total.

Features
  • Incident Log — start time, end time, and what you were trying to do when it happened
  • Auto-Calculated Downtime — total hours per incident and running total across the whole log
  • Fault Reference Tracker — the ticket number and provider response for each incident
  • Summary View — total incidents and total downtime, ready to hand a provider or ombudsman
How it works

Step by step

  1. Download the workbook and log each outage or slowdown as it happens, with start and end time.
  2. The workbook auto-calculates downtime hours for each incident and a running total.
  3. Record the fault reference number and what the provider said each time you reported it.
  4. Use the summary view when you're ready to request compensation or a contract exit.
Who it's for

Anyone dealing with repeated internet or broadband outages

Whether you're pursuing an automatic compensation scheme or building a case for a penalty-free exit, this turns scattered bad nights into an auto-calculated total.

What's included
  • Editable Excel workbook
  • Incident log with auto-calculated downtime hours
  • Fault reference tracker
  • Works on any device
