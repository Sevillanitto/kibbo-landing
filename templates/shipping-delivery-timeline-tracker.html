The problem

A delivery dispute is really a dispute about dates

When a claim about a late or missing delivery gets disputed, the exact dates rarely match anyone's memory — when it was ordered, when it dispatched, what the estimated delivery date actually was, when it stopped moving, and when you first raised the issue. Reconstructing that timeline weeks later from old emails is far weaker than a record built as each stage actually happened.

This tracker builds that chronology with a timestamp for every stage — dispatch, expected delivery, each tracking update, and the point where something went wrong — so if it does become a claim, the factual backbone is already there.

Features
  • Order & Dispatch Log — order date, dispatch date, and carrier
  • Auto-timestamped Event Log — every tracking update or status change, in order
  • Expected vs. Actual Delivery — the estimate you were given against what actually happened
  • Incident Marker — the exact point the delivery stopped matching the expected timeline
How it works

Step by step

  1. Download the Excel tracker and log the order and dispatch details as soon as you have them.
  2. Add each tracking update or status change to the event log as it happens.
  3. Compare the expected delivery date against what actually occurs.
  4. Mark the incident point if the delivery stops matching the expected timeline.
Who it's for

Anyone who wants a precise delivery record before a problem happens

Whether you're tracking a single high-value order or just want a clean habit for every delivery, this keeps the exact chronology ready if you ever need it.

What's included
  • Editable Excel workbook
  • Order/dispatch log and auto-timestamped event log
  • Expected-vs-actual delivery comparison
  • Works on any device
