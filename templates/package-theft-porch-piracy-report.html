The problem

Theft and misdelivery need different responses — check which one this is first

A package marked "delivered" that never arrives isn't automatically theft — it could be a neighbor's porch, a misread address, or a driver error, each with a different fix. Filing a theft report or a claim before ruling that out wastes time and can weaken your case. This report walks through verification first, then gives you the police report tracking and the seller-versus-carrier routing you need once theft is actually confirmed.

Features
  • Delivery Details — order, carrier, tracking, and delivery confirmation record
  • Verification Checklist — ruling out misdelivery before assuming theft
  • Police Report tracker — report number, filing date, and status
  • Seller vs. Carrier claim routing table — who's actually responsible for this claim
  • Prevention Notes — for reducing the risk of it happening again
How it works

Step by step

  1. Download the report (PDF or Excel version included).
  2. Fill in Delivery Details as soon as you notice the package is missing.
  3. Work through the Verification Checklist to genuinely rule out misdelivery before treating it as theft.
  4. File a police report if warranted and log it in the Police Report tracker.
  5. Use the Seller vs. Carrier claim routing table to file with whoever's actually responsible, and note anything in Prevention Notes for next time.
Who it's for

Anyone dealing with a package marked delivered but missing

A shipment the tracking shows as delivered that you can't find — before assuming theft, and if theft is confirmed, documenting it and routing the claim correctly.
