The problem

Individual trackers all assume you're dealing with one issue at a time

A billing dispute tracker, a records request log, a complaint file — each is built around one active issue. But healthcare paperwork doesn't stay contained to one issue: a records request from two years ago can matter to a complaint you're filing today, and without a single index across all of it, older documents are easy to forget exist.

This organizer is deliberately different from a single-issue tracker — it's a permanent, ongoing master index across every provider and every issue, kept indefinitely, not closed out when one dispute resolves.

Features
  • Master Document Index — every document, by provider, date, and issue
  • Cross-Reference Notes — link related documents to the same underlying issue
  • Storage Location Notes — where each document actually lives, physical or digital
  • Ongoing Update Log — add to it indefinitely as new documents appear
How it works

Step by step

  1. Download the organizer (PDF or Excel version included).
  2. List every healthcare-related document you currently have in the Master Document Index.
  3. Note where each one is actually stored, physical or digital.
  4. Cross-reference documents that relate to the same issue, even across different providers or years.
  5. Keep adding to it as new documents appear — it's built to stay open-ended, not to close out.
Who it's for

Anyone with an ongoing history of healthcare paperwork

Especially useful across multiple providers or years, where a single master index means nothing gets lost between issues. This is a permanent index, not a single-issue tracker — keep it alongside, not instead of, your issue-specific trackers.
