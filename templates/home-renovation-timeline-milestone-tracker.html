The problem

One delay is normal. A pattern of delays is a problem worth proving.

A single missed date rarely means much on its own — materials get held up, permits take longer than expected. But when phase after phase slips a little, and nobody's tracking it against what was originally agreed, it's hard to make the case that the project is genuinely behind, or to know which phase is actually driving the delay.

This tracker keeps the planned date and the actual date for every phase side by side, so the pattern is visible before the project ends, not just obvious in hindsight.

Features
  • Phase-by-Phase Log — every stage of the project, with its planned start/end date and actual start/end date
  • Automatic Delay Calculation — works out how many days each phase ran over as soon as an actual date is entered
  • Worst-Slippage Summary — automatically flags the single phase causing the most delay, so you know where the real problem is
How it works

Step by step

  1. List every phase of the project with the planned start and end date from your contract or schedule.
  2. Update the actual start and end date as each phase happens.
  3. Let the tracker calculate the delay for each phase automatically.
  4. Check the summary to see which phase is driving the overall slippage before raising it with your contractor.
