SEPA Recall Request Letter
Money sent to the wrong IBAN — start the recall correctly · Free

Sent a SEPA transfer to the wrong account? Start the recall.

Answer 5 questions and generate a formal SEPA Recall request to your bank. It references the standard SEPA scheme rulebook recall framework — the window to raise it and the receiving bank's typical response time — and makes clear the receiving bank cannot pull funds back without the recipient's consent unless fraud or a technical error is shown. Where Verification of Payee wasn't offered or failed, it separately flags a possible compensation claim against your own bank, distinct from the recall.
