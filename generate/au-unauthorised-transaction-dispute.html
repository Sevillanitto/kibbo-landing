Bank Dispute Letter — Unauthorised Transaction (Australia)
Invoke the ePayments Code — the burden of proof is the bank's · Free

Dispute a transaction you never made.

Answer a few questions and generate a firm dispute letter for a genuinely unauthorised transaction (stolen card, hacked account) — invoking the ePayments Code, under which you're not liable unless the bank can show you were seriously careless, and the burden of proof sits with the bank, not you.

Note: This letter is for transactions you did not authorise. If you were deceived into sending money yourself (a scam), that's currently treated as an authorised payment and the ePayments Code does not cover it — a different pathway applies.
